# Prepwise – Web-Based Aptitude Practice & Diagnostic Assessment

Prepwise is a web-based aptitude training and diagnostic evaluation platform designed to help students prepare for corporate campus placements (IT & Core) and competitive examinations (Banking, SSC, CAT).

Unlike static quiz portals, Prepwise combines strict **5-minute timed assessments** with **real-time weakness profiling** and **detailed, step-by-step analytical solutions**.

---

## 🌟 Key Features

- **3 Core Aptitude Disciplines:**
  - **Quantitative Aptitude:** Percentages, Speed-Time-Distance, Time & Work, Profit & Loss, Simple Interest, Ratios, Averages, Algebra, Mensuration.
  - **Logical Reasoning:** Number Series, Blood Relations, Syllogisms, Coding-Decoding, Direction Sense, Clock Angles, Analogies.
  - **Verbal Ability:** Subject-Verb Agreement, Synonyms, Antonyms, Idioms & Phrases, Spelling, One-Word Substitution, Articles & Prepositions.
- **5-Minute Timed Mock Tests:** Exam-simulated countdown timer with individual per-question speed tracking.
- **Deep Step-by-Step Answer Explanations:**
  - 3-step arithmetic and deductive derivations ($1 \rightarrow 2 \rightarrow 3$).
  - Core mathematical formulas & grammatical rules.
  - ⚡ **Speed Shortcut Tips:** Mental math shortcuts to save 30–40 seconds in competitive exams.
  - ⚠️ **Common Pitfalls:** Highlights deceptive reasoning traps and calculation mistakes.
- **Live Weakness Detection & Analytics:**
  - Automatically flags subtopics where accuracy is $< 60\%$.
  - Displays actionable remedial advice tailored to each weak topic.
  - Highlights strong topics ($\ge 75\%$ accuracy) and user-declared career interest areas.
- **Interactive Student Authentication & Profiles:**
  - Sign in, account registration, and zero-friction guest mode.
  - Customizable target career goals (Campus Placements, Banking, CAT, Core Engineering).
  - Revision bookmarking system for tricky questions.
  - Persistent storage powered by HTML5 `localStorage` (runs 100% offline or online without external database setup).

## 🚀 Quick Start / How to Run

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
3. No server, database, or `npm install` needed—it is completely self-contained.

## 🌐 Deploy Free on GitHub Pages

1. Go to your repository's **Settings** tab.
2. Navigate to **Pages** on the left sidebar.
3. Under **Branch**, select `main` and root folder `/ (root)`, then click **Save**.
4. Your site will be published live at `https://<your-username>.github.io/<repo-name>/`.
